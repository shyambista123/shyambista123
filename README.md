### About

I build event-driven backends that move data and money reliably — Kafka pipelines, change-data-capture, and the Kubernetes clusters that keep it all running in production.

- 🏦 Backend engineer, mostly in fintech / digital lending
- 🔁 Focused on event-driven systems — Kafka, CDC, Redis
- ☁️ Ship and run services on Kubernetes via Argo CD & Jenkins
- 🌱 Background in Django REST APIs before moving into Java/Spring Boot

---

### Focus Areas

**Event-driven backends**
Java services on Spring Boot, talking through Kafka and Redis, with CDC keeping downstream systems in sync.

**Cloud-native delivery**
CI/CD through Jenkins, deployed and managed on Kubernetes and Rancher, synced via Argo CD.

**Data & tooling**
Comfortable across relational stores and scripting — MySQL and PostgreSQL, Python and Django, Linux and Git day to day.
